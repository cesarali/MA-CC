## 1. The experiments

Two setups, the **same world** (`task_003`, latent vector `(3,1,1,2,2,1,1,1,2)`,
scores 8 / 4 / 6, `ALLOCATION_0` correct). Same 49-fact universe, same 24 agents
holding one fact each. **They differ only in which facts the agents hold.**

| | `task003-symmetric-v2` | `task003-nosolution-v2` |
|---|---|---|
| distinct facts held | 16 | 15 |
| slot lean A0/A1/A2 | 8 / 8 / 8 | 8 / 8 / 8 |
| agents' joint posterior | **[1.0, 0, 0]** | **[0.5, 0, 0.5]** |
| decisive facts held | 6 of 6 | 0 of 6 |
| proofs assemblable | 8 | 0 |
| accuracy ceiling | 1.0 | 0.5 |
| **the question** | can the swarm find a proof it owns, and can a controller stop it? | can a controller tip a genuinely undecided swarm? |

Both share **one 12-fact controller pool**: lean 4/4/4, strength-matched, joint
posterior on the prior, **proving no allocation**, **zero overlap** with the
agents' facts, and **identical for both steering directions** — so any
directional difference is the selection policy, not the menu.

**Arms:** silent (no controller) / truth control (`ALLOCATION_0`) / false
control (`ALLOCATION_2`), crossed with ρ ∈ {0.75, 1.0}.
**= 12 cells, 1,200 episodes** at 100 episodes × 30 rounds.

## 2. Decisions made

| area | decision | why |
|---|---|---|
| **agent communication** | `report_only` | reports are the only channel carrying facts, and facts are the whole treatment |
| **controller actuation** | `adaptive_communication` | only this and `truthful_strategic_report` can post a pool fact at all |
| **controller authoring** | `deterministic` first, `llm_authored` second | makes the dose a known function of the sensed state, and is the reference the LLM controller is scored against |
| **message mode** | `recommendation_only` | keeps the separate peer-slot channel factless so every controller fact arrives through the pool |
| **board reading** | `sampling: full` | departs from Darius's `uniform` at 7 of 15, which adds a per-round reading lottery on top of epistemic decay |
| **citation scope** | `active_or_observed` | this is the propagation mechanism; `active_only` would make the board inert |
| **activation gate** | `advocacy_schedule: always` | with `soft` the archived batch fired on 32% vs 54% of rounds, and that gap was most of the apparent directional effect |
| **timing** | `dawn_only` | `microscopic` interleaves within the round, which produced the ordering artifact that invalidated the earlier dose-response result |
| **budget** | **`b = 3` per round** | an episode reservoir makes the remaining budget a hidden, monotone state variable outside the 4-state coarse-graining |
| **pool resolution** | `controller_report_pool_mode: frozen` with our 12 facts in `facts/controller_reportable_facts.json` | `frozen` is already target-independent; and `controller_fact_pool_mode: balanced` would force `base_score = 0` and make deterministic selection target-blind |
| **rounds** | 30 | path divergence is still rising at h = 14, so 15 truncates it |
| **episodes** | **100** (post-meeting_plan says 50) | the bootstrap resamples whole episodes; 50 extrapolates to ±33% on the headline quantity against the ±18% measured at 168 |
| **merge** | **done** | `controller_budget_scope` for the later episode-budget phase |

## 4. The scoring question, restated

With `deterministic` authoring the controller ranks its pool on

```
(not cooldown_eligible, reuse_count, live_count, -base_score, tie_hash, fact_id)
```

and posts the top `b`. **The only target-sensitive term is `-base_score`**,
read from `task.controller_fact_scores`. The tie-break hash is over
`(episode_seed, task_id, round_index, fact_id)` — not the target.

So if those scores are absent or equal, **the fact choice is target-blind**:
both arms rotate through the same 12 facts in the same order and differ only in
the recommendation text.

There is **one score field per task**, so it cannot encode two opposite targets.
Three ways out:

| option | effect | cost |
|---|---|---|
| **two task directories per setup** (4 total), identical facts and pool, differing only in the score field | what the design intends | ugly but auditable; a diff shows one field changed |
| **accept target-blind fact choice** | narrower question: *does a recommendation steer, with evidence held constant?* | free — just omit the scores |
| **compute the score at runtime** from the resolved target against the exact posterior | the proper fix | a code change to shared code, needs tests |

Running the first two **together** is attractive: the contrast separates
**evidence selection** from **bare recommendation**, which neither setup
currently answers.

### Design defects identified in prior work

| what | consequence |
|---|---|
| **The archived controller pool is target-confounded.** Fact admission was evaluated once for `ALLOCATION_2` and reused for the truth arm, so both arms quote the same 24 facts and the truth arm cites evidence chosen to undermine it. Measured target information 0.022 bits | the archived truth-arm numbers say nothing about truth-directed steering |
| **`balanced` pool mode forces `base_score = 0`** whenever pool mode ≠ `frozen`, so `balanced` + `deterministic` cannot select facts toward a target | Darius's `29-09-2026-task004-classical-b3-gated-balanced` truth and false arms differ only in the recommendation text. Worth asking whether that was intended |
| **`task_004` removed the decisive facts together with their holders**, dropping 24 agents to 15 | confounds proof availability with population size, distinct-fact count (21 → 15) and redundancy. Both v2 setups hold the population at 24 |
| **Rival-leaning facts are the scarce resource.** 9 A1-leaning and 9 A2-leaning against 31 A0-leaning, and the `balanced` rule takes all 18 | every fact outside that pool is A0-leaning, so any lean-balanced agent set must overlap it by exactly two thirds. The 10-of-15 overlap was forced by the rule, not a tuning accident |
| **Agents already read only part of the board.** `sampling: uniform` with `social_group_size: 7` of 15 | partial observation the post-meeting_plan never mentions; inherited, never chosen |

### Errors in my own earlier analysis, corrected

| claim | correction |
|---|---|
| "the post-meeting_plan puts report-only ahead of full communication" | **Backwards.** Its priorities 1–2 are full communication; report-only is 3–4 |
| "merging is a prerequisite for phase 1" | **No.** The `frozen` route runs unmerged; the merge is for the episode budget |
| "the decisive-fact factor is novel" | **No.** `task_004` *is* `task_003` minus the decisive facts, recorded in its `task.json` |
| "the frozen task files live on the cluster and are not needed" | They were on `darius-MA-v1`, including the per-agent assignments |
| "agents hold private packets of facts" | **Each agent holds exactly one fact** |
| "`recommendation_plus_fact` attaches a fact to a private message" | It is the peer-slot channel, carrying at most one fact fixed for the whole episode |
| "both controllers quote 24 decoy-favouring facts" | Their individual leans are 9/6/9; the decoy tilt is in the **joint** posterior, [0.308, 0, 0.692] |
| `social_group_size: 24` | Must be ≤ `population_size − 1`, so 23 — and it is inert under `sampling: full` |
