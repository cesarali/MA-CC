# Reports of the 15-agent campaign

One folder per analysis session, named `YYYY-MM-DD_<topic>/` (the date the report is written). Each holds a
LaTeX/PDF report, its figures, and the script that makes the figures from the run outputs. Reports first evaluate the
pre-registered predictions (`../00_preregistration.md`), then any exploratory analysis, clearly labelled.

Run outputs are not here. They are in `../results/` (gitignored; the dated run folders written by the Simulation 2
runner, with `manifest.json` and `summary.csv`).
