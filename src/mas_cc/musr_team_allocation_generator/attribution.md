# MuSR attribution

This generator is an independent MAS-CC implementation inspired by the Team
Allocation task and entailment-tree design in:

> MuSR: Testing the Limits of Chain-of-thought with Multistep Soft Reasoning  
> Zayne Sprague et al.

- Upstream repository: <https://github.com/Zayne-sprague/MuSR>
- Pinned reference commit: `b1f4d4168a9cfc6760e8b74d728e4516023dfaa5`
- Upstream license: MIT
- Upstream copyright: Copyright (c) 2024 Zayne Sprague

No MuSR runtime dependency is used. The exact allocation solver, typed tree,
structured prompts, distribution, validation, and MAS-CC provider adapter were
implemented locally. The upstream MIT license text is preserved in
`musr_team_allocation_generator/LICENSES/MuSR-LICENSE.txt`.
