# Santa Fe Cygnus results, 2026-09-26

- `santa_fe_brief.pdf` is the 12-page scientific summary, model and parameter
  ledger, mean-field starting point, selected figures, and exact submitted
  YAML recipes.
- `santa_fe_results.pdf` is the self-contained 330-page version with every
  generated figure in an indexed atlas: 88 original-sweep plots, 544 rho-sweep
  plots, and 2 calibration plots.
- `santa_fe_brief.tex` and `santa_fe_results.tex` are the LaTeX source snapshots.
  Their image paths refer to the Cygnus result tree at
  `/shared/home/cesar/work/results/studies/`. The PDFs contain the images and
  can be read without that tree.
- `figure_manifest.csv` maps figure IDs to source PNG paths below the result
  root and records their SHA-256 hashes.

The raw trajectories and estimator outputs remain in the Cygnus result roots
documented in `docs/handoff/25092026_santa_fe_cygnus_parallel_handoff.md`
and `docs/handoff/26092026_santa_fe_rho_phase_cygnus.md`.
