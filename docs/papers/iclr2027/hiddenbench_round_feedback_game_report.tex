\paragraph{Status.}
This document specifies the next version of the HiddenBench imitation game.
It is a \emph{new game derived from}, but not a silent modification of, the
currently implemented event-level \texttt{hidden\_bench\_imitation} game.
The purpose of the redesign is to place the controller on a slower and more
realistic timescale than the microscopic population dynamics while preserving
the one-focal-agent imitation geometry and the matched reasoning/classical arms.

\MethodologyHeading{Scientific object}

A HiddenBench task provides a scenario, shared information $I_s$, distributed
hidden information $I_u$, a finite answer set
\[
\mathcal A=\{a_1,\ldots,a_K\},
\]
and a correct option $o^\star$.  Agent $i$ carries its assigned evidence and a
current opinion
\[
X_i\in\mathcal A.
\]
The labelled population state is
\[
\bm X=(X_1,\ldots,X_N),
\]
and the mesoscopic occupation state is
\[
\Nstate=(n_1,\ldots,n_K),
\qquad
n_j=\sum_{i=1}^{N}\1[X_i=a_j],
\qquad
\sum_jn_j=N.
\]
As in the existing imitation game, one microscopic update changes at most one
focal opinion.

The experiment has two matched dynamical arms:
\begin{align*}
\text{reasoning ON:}&\quad \text{the focal LLM updates from its evidence,
history, and current social input},\\
\text{reasoning OFF:}&\quad \text{an explicit provider-free stochastic
transition kernel updates the focal opinion}.
\end{align*}
The task, initialization, population, social scheduler, controller, and recorded
observables should otherwise be matched.

\MethodologyHeading{Two clocks}

The redesign introduces an explicit separation between a fast population clock
and a slow feedback clock.

Let $k=0,1,\ldots$ index \emph{population rounds}.  Each round contains exactly
$N$ microscopic focal-update opportunities, indexed by
$r=1,\ldots,N$.  Write
\[
\Nstate_{k,0}\equiv \Nstate_k,
\qquad
\Nstate_{k,N}\equiv \Nstate_{k+1}.
\]
The controller senses and chooses an action only at the round boundary.  It does
not re-measure or reconsider its decision after individual opinion changes
inside that round.

The three principal interaction resources are
\[
q=\text{social influence slots per microscopic update},
\]
\[
q_c=\text{agents sensed once per round},
\]
and
\[
b=\text{controlled microscopic positions in an ADVOCATE round}.
\]
For cross-population comparisons define the intensive sensing and actuation
fractions
\[
r_s=\frac{q_c}{N},
\qquad
r_a=\frac{b}{N}.
\]
These are distinct resources: $q_c$ controls observation capacity, whereas $b$
controls actuation capacity.

\MethodologyHeading{Round-level feedback protocol}

At the beginning of round $k$ the controller sees only a noisy population
measurement.  For a fixed target $Z\in\mathcal A$, it samples a set
$S_k$ of $q_c$ agents uniformly without replacement and observes
\[
Y_k=\{X_i:i\in S_k\}.
\]
For target support it is convenient to use
\[
s_k=\frac{1}{q_c}\sum_{i\in S_k}\1[X_i=Z].
\]
Conditioned on the round-boundary population state, the target-support count is
hypergeometric.

The default feedback policy remains stochastic and soft:
\[
\Pr(U_k=\Adv\mid Y_k)
=
\sigma\!\left(\beta(\vartheta-s_k)\right),
\qquad
\sigma(x)=\frac{1}{1+e^{-x}},
\]
with
\[
U_k\in\{\Noop,\Adv\}.
\]
The soft policy is scientifically useful because comparable states retain
positive support for both actions.

If $U_k=\Noop$, all $N$ microscopic updates are ordinary social updates.

If $U_k=\Adv$, choose exactly
\[
B_k\subset\{1,\ldots,N\},
\qquad |B_k|=b,
\]
uniformly at random \emph{once, before the first microscopic update}.  The set
$B_k$ is the complete actuation schedule for that round.  There is no further
controller sensing or decision until $k+1$.

Define
\[
C_{k,r}=\1[r\in B_k].
\]
At each microscopic position $r$, sample one focal agent and $q$ distinct
ordinary peers from the \emph{current} population state.  If $C_{k,r}=0$, the
focal receives all $q$ ordinary social inputs.  If $C_{k,r}=1$, one of the $q$
social slots is replaced by a controller advocacy message for $Z$, so the focal
still receives exactly $q$ influence slots:
\[
q=(q-1)\ \text{ordinary peers}+1\ \text{controller advocacy}.
\]
The controller does not overwrite the focal vote.  It only changes the local
information/social context.

This is a sampled-data, partially observed feedback controller with a fixed
per-round intervention budget.  The plant evolves on the microscopic clock;
measurement and policy updates occur on the slower round clock.

\MethodologyHeading{Controller semantics}

The controller is external to the population:
\begin{itemize}[leftmargin=1.5em]
    \item it has no vote;
    \item it receives no hidden HiddenBench evidence;
    \item it does not access private agent memories;
    \item its advocacy message should remain peer-style and should not announce
    that it is an external controller;
    \item it never forces the focal answer.
\end{itemize}
The initial target may be $Z=o^\star$.  A later wrong-target condition
$Z\neq o^\star$ should be supported so that control success and truth alignment
can be separated.

Microscopic reversibility is \emph{not} part of the game definition.  A
reversible classical special case may be useful for comparison with the
stochastic-thermodynamic framework of Irisarri et al.~\cite{irisarri2026}, but
the control mechanism should be chosen for plausibility and tractability rather
than engineered solely to preserve detailed balance.

\MethodologyHeading{Macroscopic observables}

For option $Z$ define
\[
p_Z=\frac{n_Z}{N},
\qquad
m_Z=\frac{Kp_Z-1}{K-1}.
\]
The principal observables remain
\[
m_{\rm truth}=m_{o^\star},
\qquad
m_{\rm ctrl}=m_Z,
\]
\[
m_{\rm order}
=
\frac{K\max_j p_j-1}{K-1},
\]
and normalized vote entropy
\[
H_{\rm vote}
=
-\frac{\sum_jp_j\ln p_j}{\ln K}.
\]
When $Z=o^\star$, $m_{\rm ctrl}=m_{\rm truth}$; the fields should nevertheless
remain distinct to support wrong-target experiments.

\MethodologyHeading{Information analysis at the correct timescale}

The round-level causal tuple is
\[
\boxed{
\Nstate_k\longrightarrow Y_k\longrightarrow U_k
\longrightarrow \Nstate_{k+1}.
}
\]
The primary controller-to-population information quantity is therefore
\[
\boxed{
\mathcal T^{\rm round}_{U\to N}
=
I(U_k;\Nstate_{k+1}\mid \Nstate_k)
}
\]
in bits per population round.  In a Markov classical model this is the
one-step transfer entropy at the feedback timescale.  In the reasoning arm it
is the corresponding first-order empirical directed-information statistic; a
later history-conditioned analysis can test whether the round-boundary state is
insufficient because of LLM memory.

The corresponding round-level sensing quantity is
\[
I(\Nstate_k;Y_k).
\]
Useful lower-dimensional actuation projections are
\[
I(U_k;n_{Z,k+1}\mid n_{Z,k}),
\qquad
I(U_k;n_{{\rm truth},k+1}\mid n_{{\rm truth},k}),
\]
together with
\[
H(U_k\mid \Nstate_k)
\]
and the information fraction
\[
\rho_N
=
\frac{I(U_k;\Nstate_{k+1}\mid\Nstate_k)}
     {H(U_k\mid\Nstate_k)}.
\]
The ratio is a normalization diagnostic, not a thermodynamic efficiency.

A signed round response should accompany the unsigned CMI, for example the
state-adjusted difference
\[
\mathbb E[\Delta m_Z\mid U_k=\Adv,\Nstate_k]
-
\mathbb E[\Delta m_Z\mid U_k=\Noop,\Nstate_k]
\]
over states with action overlap.

\paragraph{Why this is a new analysis layer.}
The old event-level statistic
$I(U_t;\Nstate_{t+1}\mid\Nstate_t)$ cannot simply be averaged or summed to obtain
the round quantity.  All $N$ microscopic transitions in a controlled round share
one action and are coupled through the evolving state.  Therefore the new game
must persist one explicit round record and compute the information statistics
from round-boundary samples.

\MethodologyHeading{Microscopic and episode diagnostics}

The microscopic event log should be retained.  It is useful for asking what the
preallocated intervention actually does locally.  Within ADVOCATE rounds,
$C_{k,r}$ is randomized in advance, so a useful local diagnostic is
\[
I(C_{k,r};X^{f}_{k,r+1}
\mid X^{f}_{k,r},\Nstate_{k,r},U_k=\Adv),
\]
plus signed focal target-adoption/target-leaving responses.  This is a local
intervention diagnostic, not the headline round-level transfer entropy.

Episode-level trajectory quantities should also remain, including final truth
alignment and the net truth current
\[
J_{\rm truth}
=
N_{\to {\rm truth}}-N_{\leftarrow {\rm truth}},
\]
together with activity
\[
A_{\rm truth}
=
N_{\to {\rm truth}}+N_{\leftarrow {\rm truth}}.
\]
Because $J_{\rm truth}$ telescopes under one-focal updates, activity is required
to distinguish quiet and highly fluctuating paths with the same endpoint.

\MethodologyHeading{Estimation and support}

Round-level information estimates should be pooled across repeated episodes
within a fixed experimental cell, while uncertainty is obtained by resampling
whole episodes.  They should not be estimated separately from one short
episode.

The coarser feedback clock reduces the number of information samples by roughly
a factor of $N$ relative to the old event-level analysis.  Consequently:
\begin{itemize}[leftmargin=1.5em]
    \item full-state CMI may be sparse for large $N$ and $K$;
    \item target-count projections are important robustness diagnostics;
    \item action-overlap and singleton/sparsity diagnostics must be reported;
    \item more repeated episodes may be required than in the event-level game.
\end{itemize}

Because the stochastic policy is known, a natural null for actuation is a
conditional-randomization null that resamples
\[
U_k^\star\sim\pi(\cdot\mid Y_k)
\]
from the logged policy probability while holding the observed state and outcome
records fixed.  This preserves the measurement-to-policy coupling while
destroying the observed action-to-outcome association.  Episode-level bootstrap
uncertainty should remain the default uncertainty calculation.

\MethodologyHeading{Scientific comparison}

The central controlled comparison is
\[
\begin{array}{c|cc}
 & \text{no feedback} & \text{round feedback}\\
\hline
\text{reasoning ON} & A & B\\
\text{reasoning OFF} & C & D
\end{array}
\]
with matched task, initialization, $N$, $q$, round horizon, and seeds where
possible.  The main structural control axes are now
\[
(q,\ q_c/N,\ b/N),
\]
with $N$ providing the finite-size dimension.

The theory target is an explicit classical round kernel
\[
R_u(\Nstate_{k+1}\mid\Nstate_k)
\]
and its exact or approximate transfer entropy.  The LLM experiment then asks
whether semantic reasoning changes controllability, fluctuations, and the
adequacy of the Markov round-boundary description.

\MethodologyHeading{What this redesign does and does not claim}

The redesign is motivated by a clearer physical interpretation of feedback:
a controller observes the population, commits a finite intervention budget for
a slower interval, lets the population evolve, and measures again.  It also
separates sensing capacity from actuation capacity, which were not independent
resources in the old event-level protocol.

It does \emph{not} invalidate the existing event-level results.  Those results
belong to a different controller/game and should remain reproducible under the
old \texttt{hidden\_bench\_imitation} type.  Numbers from the old event-level CMI
and the new round-level CMI should not be presented as the same estimator at a
different plotting resolution.
